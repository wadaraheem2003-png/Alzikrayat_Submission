## Alzikrayat – Memories Photo Gallery

About the Project
Alzikrayat is a web application that allows users to save, organize, and manage their favorite photos and memories.

## Features
- User Registration and Login.
- Secure User Authentication.
- Upload and View Photos.
- Edit Photo Information.
- Delete Photos.
- Personal Photo Gallery.

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB
- JavaScript
- CSS

## Installation
1. Install dependencies in both "client" and "server" folders:
npm install
2. Configure the server ".env" file with the required environment variables.
3. Start the backend:
node index.js
4. Start the frontend:
npm run dev
